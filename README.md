## 🚀 Programs Included

### 1. Greeting Program 👋
A simple script that:
- Prompts the user for their first and last name
- Combines them into a full name
- Prints a personalized greeting

Enter your first name: Mark
Enter your last name: Anderson
Hello, Mark Anderson! Welcome to learning python.

first_name = input("Enter your first name: ")
last_name = input("Enter your last name: ")
full_name = first_name + " " + last_name
print(f"Hello, {full_name}! Welcome to learning python.")

2. Arithmetic Operations ➕➖✖️➗
A script that:
Prompts the user for two numbers
Performs addition, subtraction, multiplication, and division
Displays results clearly

enter first number: 100

num1 = input("enter first number: ")
