# Greeting Program 👋

A beginner-friendly Python script that demonstrates how to:
- Take user input
- Concatenate strings
- Print a personalized greeting

---

## 🚀 Features
- Prompts the user for their first and last name
- Combines them into a full name
- Displays a friendly welcome message

---

Usage
Run the script in your terminal:

python greeting.py
Sample interaction:

Code
Enter your first name: Mark
Enter your last name: Anderson
Hello, John Doe! Welcome to learning python.
📚 Code Overview
python
# 1. Take user's first and last name as input
first_name = input("Enter your first name: ")
last_name = input("Enter your last name: ")

# 2. Concatenate first and last name into a full name
full_name = first_name + " " + last_name
----


# 3. Print a personalized greeting message
print(f"Hello, {full_name}! Welcome to learning python.")
